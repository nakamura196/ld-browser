このツールについて

LD Browser は、URI を入れると、その資源を説明する RDF をブラウザが直接取りに行き、表とグラフにする道具です。リンクを押すと、次の資源へたどれます。

サーバを持たない

取得も表示も、すべて見ている人のブラウザの中で行います。中継のサーバが無いので、使う人が増えてもどこかに負荷が集まりません。

そのかわり、読めるのは別サイトからの読み込み（CORS）を許可している相手だけです。許可していない相手は「読み込めませんでした」と出ます。転送（301・303）の途中に許可の無い段があるときも、同じく読めません。

読める形式

  • Turtle、N-Triples、N-Quads、TriG、JSON-LD、RDF/XML
  • HTML の頁に埋め込まれた JSON-LD（<script type="application/ld+json">）、microdata、RDFa

2 MB を超える文書は読みません。

読み替え

Wikidata の URI は、軽い Turtle の版（Special:EntityData/…​.ttl?flavor=simple）を取りに行きます。http:// の URI は https:// に替えます。SKOS や Dublin Core のように転送の途中で許可が切れる語彙は、転送の終点を直接取りに行きます。

着想

神崎正英さんの LD Browser（2014）に学びました。神崎さんの版はサーバで取得する作りで、2026 年 10 月現在、アクセス過多のため止まっています。この道具はそれとは別に作ったもので、神崎さんの道具ではありません。
