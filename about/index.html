このツールについて

Musubi（結び）は、URI を入れると、その資源を説明する RDF をブラウザが直接取りに行き、表とグラフにする道具です。リンクを押すと、次の資源へたどれます。

ふだんはサーバを使わない

取得も表示も、ふだんは見ている人のブラウザの中で行います。使う人が増えても、どこかに負荷が集まりません。

ブラウザが直接読めるのは、別サイトからの読み込み（CORS）を許可している相手だけです。転送（301・303）の途中に許可の無い段があるときも読めません。

許可の無い相手のうち、国立国会図書館の典拠など一部に限って、中継のサーバ（Vercel）を通して取りに行きます。直接読めなかったときだけ使い、画面に「中継を通して取得しました」と出ます。中継の対象に入っていない相手は「読み込めませんでした」と出ます。

読める形式

  • Turtle、N-Triples、N-Quads、TriG、JSON-LD、RDF/XML
  • HTML の頁に埋め込まれた JSON-LD（<script type="application/ld+json">）、microdata、RDFa

2 MB を超える文書は読みません。

読み替え

Wikidata の URI は、軽い Turtle の版（Special:EntityData/…​.ttl?flavor=simple）を取りに行きます。http:// の URI は https:// に替えます。SKOS や Dublin Core のように転送の途中で許可が切れる語彙は、転送の終点を直接取りに行きます。

名前

Musubi（結び）は、データとデータを結ぶ道具、という意味で付けました。2026 年 11 月までは LD Browser という名前で、browser.ldas.jp で公開していました。IIIF の画像を扱う Kasane、TEI の翻刻を扱う Awase と同じ見た目にそろえています。

着想

神崎正英さんの LD Browser（2014）に学びました。神崎さんの版はサーバで取得する作りで、2026 年 10 月現在、アクセス過多のため止まっています。
