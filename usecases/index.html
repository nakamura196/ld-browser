ユースケース

公開されている Linked Data を、Musubi で開いた例です。押すとその資源が開き、そこからリンクをたどれます。読めない相手の例も 1 つ入れてあります。

  • ジャパンサーチ

    浮世絵から、作者と各国の典拠へ

    東京国立博物館の「冨嶽三十六景・神奈川沖浪裏」。画像が出て、作者・時代・所蔵館は入れ子で開きます。作者の葛飾北斎からは、Wikidata・DBpedia・VIAF・国立国会図書館の同じ人へ渡れます。

    • 画像
    • 入れ子
    • 機関をまたぐ
    • グラフ
    https://jpsearch.go.jp/data/cobas-52087
    Musubi で開く元のサイト
  • ジャパンサーチ

    1 人の人物を、機関をまたいで結ぶ

    ジャパンサーチの人物の典拠「葛飾北斎」。別名がかな・英語つきで並び、owl:sameAs で各国の典拠と結ばれています。グラフにすると、その結び目が一目で分かります。

    • 機関をまたぐ
    • グラフ
    https://jpsearch.go.jp/entity/chname/葛飾北斎
    Musubi で開く元のサイト
  • DBpedia

    Wikipedia から作られた Linked Data

    DBpedia の「Hokusai」。DBpedia は https の URI を http の住所へ転送するため、そのままではブラウザから読めません。Musubi は転送先の Turtle を直接取りに行きます。

    • 読み替え
    • 機関をまたぐ
    http://dbpedia.org/resource/Hokusai
    Musubi で開く元のサイト
  • 米国議会図書館

    米国議会図書館の名前典拠

    米国議会図書館の典拠（id.loc.gov）の葛飾北斎。JSON-LD で返ってくる、入れ子の深いデータです。異表記や典拠の出典が、入れ子のまま読めます。

    • JSON-LD
    • 入れ子
    http://id.loc.gov/authorities/names/n80043599
    Musubi で開く元のサイト
  • GeoNames

    地名の典拠と緯度経度

    GeoNames の「東京」。RDF/XML で返ってきます。多言語の地名と緯度経度、上位の地名（日本）へのリンクがあります。

    • RDF/XML
    https://sws.geonames.org/1850147/
    Musubi で開く元のサイト
  • 社会実験事例データベース

    研究プロジェクトのデータを、語彙ごと読む

    東京大学の低炭素社会実験の事例（sedb）。元のドメインは止まっていますが、公開されている Turtle に読み替えます。独自の語彙も読むので、属性名が日本語で出ます。

    • 読み替え
    • 語彙
    http://low-carbon.k.u-tokyo.ac.jp/059cc1cca31ac7400e89b9d80ec880cb
    Musubi で開く元のサイト
  • RailClass

    鉄道車両の形式を、Wikidata の名前で

    鉄道車両の形式のデータ（RailClass）の ICE T。運営者や路線は Wikidata の名前で日本語になり、3D モデルや塗装の色まで自動で開いてたどれます。

    • 入れ子
    • 画像
    • 読み替え
    https://w3id.org/railclass/Q696668
    Musubi で開く元のサイト
  • W3C

    語彙の定義を引く

    SKOS の skos:prefLabel。属性の URI をそのまま開くと、その定義が読めます。転送の途中で許可が切れる語彙なので、Musubi は転送の終点を直接取りに行きます。

    • 語彙
    • RDF/XML
    • 読み替え
    http://www.w3.org/2004/02/skos/core#prefLabel
    Musubi で開く
  • schema.org

    Web 頁に埋め込まれたデータを取り出す

    schema.org の about の頁。ふつうの HTML の頁ですが、中に埋め込まれた JSON-LD・microdata・RDFa を取り出して表にします。

    • HTML 埋め込み
    • 語彙
    https://schema.org/about
    Musubi で開く
  • 国立国会図書館

    許可の無い相手は、中継して読む

    国立国会図書館の典拠（Web NDL Authorities）の葛飾北斎。RDF は返ってきますが、別のサイトからの読み込み（CORS）が許可されていないので、ブラウザだけでは読めません。こうした相手に限って、Musubi は中継のサーバを通して取りに行きます。

    • 中継
    • RDF/XML
    http://id.ndl.go.jp/auth/entity/00270331
    Musubi で開く元のサイト
