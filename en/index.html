Read as a table

One row per property. Blank nodes and resources in the same document are nested; other documents open in place with ▸. Names prefer English.

See as a graph

Tables of up to 300 triples can be drawn as a graph. Drag nodes, click one to open that resource, or save as SVG.

Many formats

Turtle, N-Triples, JSON-LD and RDF/XML, plus JSON-LD, microdata and RDFa embedded in HTML.

How it works

  1. Rewrite Decide where the RDF can be fetched from the URI (a Turtle version for Wikidata, https for http).
  2. Fetch Your browser requests it directly from the other server. There is no relay server.
  3. Show Collect names and render a table and a graph. Click a link to move to the next resource.

With no relay server, it does not stop when more people use it. In return, sites that do not allow cross-origin requests (CORS) cannot be read.Details

There is no server: your browser fetches the RDF directly. It can only read sites that allow cross-origin requests (CORS).
